# Verification history

These are historical local records, not a claim that the current scope is complete. Earlier installers were unsigned and tested with isolated profiles on the development host. Archive integrity or silent installation does not qualify an interactive installer on clean Windows. Limited synthetic AI checks do not establish educational effectiveness.

Detailed pre-0.14 narratives are retained in Git history rather than repeated in the current requirements matrix. Local versioned receipts use `test-results/release-<version>-verification.json`; feature checks/screenshots are also ignored development evidence. Historical requirement totals reflect an earlier scope and are not the current completion score.
